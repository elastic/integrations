# Elastic Crawlers

A crawler is a type of Elastic integration that performs a one-way sync of data from an original data source to an Elasticsearch index. 

Crawlers extract the original files, records, or objects, and transforms them into Elasticsearch documents - enabling you to create searchable, read-only replicas of your data sources.

Crawlers were renamed from Elasticsearch Connectors and you may see older versions of documentation still refer to them by their old name. 

Read our documentation to learn more about the available [Elastic Crawlers](https://www.elastic.co/guide/en/elasticsearch/reference/current/es-connectors.html)
