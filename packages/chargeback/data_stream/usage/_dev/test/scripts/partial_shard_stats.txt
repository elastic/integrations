# Test 3-poll partial shard failure and recovery sequence (healthy -> partial -> healthy):
# 1. Poll A (healthy, _shards.failed == 0): establishes full multi-shard baselines for
#    orders-2026.01.01 (2 primaries, 2,000,000 ms), truncated-2026.01.01 (1 primary + 1 replica,
#    1,000,000 ms), and healthy-2026.01.01 (1 primary, 500 ms).
# 2. Poll B (partial, _shards.failed == 3):
#    - Emits 1 error.code == "partial_shard_stats" diagnostic document.
#    - Emits best-effort delta (50 ms) tagged partial_shard_stats == true for unaffected healthy-2026.01.01.
#    - Skips orders-2026.01.01 via _shards.failures[].index so its Poll A baseline is preserved.
#    - Skips truncated-2026.01.01 via cur_sc < prev_sc fallback (omitted from _shards.failures[])
#      so its Poll A baseline is preserved.
#    - Skips broken-2026.01.01 (0 responding shards, partial_empty).
# 3. Poll C (healthy recovery, _shards.failed == 0):
#    - Computes exact Poll A -> Poll C deltas without lifetime-counter inflation:
#      * orders-2026.01.01: index_time_in_millis_delta == 200 (not 1,000,100),
#        query_time_in_millis_delta == 80, query_total_delta == 8, docs.count_delta == 100.
#      * truncated-2026.01.01: index_time_in_millis_delta == 90 (not 500,050),
#        query_time_in_millis_delta == 20, query_total_delta == 4.
#      * healthy-2026.01.01: index_time_in_millis_delta == 60 (partial_shard_stats absent).
#      * broken-2026.01.01: initial healthy baseline document (1 doc, no delta).

#   Poll C: 4 healthy index_usage (healthy delta, orders delta, truncated delta, broken baseline) = 4
