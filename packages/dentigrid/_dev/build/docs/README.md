# DentiGrid Active Deception Integration

Official Elastic Integration for **DentiGrid** active deception fabric, honeypot traps, and zero-false-positive threat intelligence.

## Overview

**DentiGrid** is an active cyber deception fabric designed to intercept ransomware, advanced persistent threats (APTs), and internal lateral movement before critical assets are compromised.

By deploying distributed decoy services (SMB, RDP, SSH, MSRPC, HTTP, SCADA/ICS), synthetic canary credentials, and breadcrumb tokens across corporate subnets, DentiGrid forces attackers into deterministic tripwires. Because legitimate users and applications have no reason to access deception assets, every alert generated by DentiGrid is a high-confidence true positive.

## Data streams

The DentiGrid integration collects one data stream: **threat**.

### Threat

The `threat` data stream collects high-fidelity deception events, decoy intercepts, and honeynet telemetry from DentiGrid sensors and the API gateway.

#### Ingestion options

1. **Elastic Agent CEL Input (API Gateway):** Polls real-time threat events from the DentiGrid API Gateway.
2. **Elastic Agent Filestream Input (Log Files):** Tails local JSON log files emitted by DentiGrid sensor daemons (`/var/log/dentigrid/*.json`).

## Requirements

Elastic Agent must be installed and enrolled in Fleet.

## Setup & Configuration

1. In Kibana, navigate to **Management > Integrations**.
2. Search for **DentiGrid** and click **Add DentiGrid**.
3. Choose either the **CEL** poller for API Gateway ingestion or **Filestream** for local sensor logs.
4. Add the integration to an Elastic Agent policy.
