# DentiGrid Elastic Security (ELK) Integration

Official **Elastic Package Registry (EPR)** integration for **DentiGrid** active deception fabric, honeypot traps, and zero-false-positive threat intelligence.

---

## Overview

**DentiGrid** is an active cyber deception fabric designed to intercept ransomware, advanced persistent threats (APTs), and internal lateral movement before crown-jewel assets are compromised.

By deploying distributed decoy services (SMB, RDP, SSH, MSRPC, HTTP, SCADA/ICS), synthetic canary credentials, and breadcrumb tokens across corporate subnets, DentiGrid forces attackers into deterministic tripwires. Because legitimate users and applications have no reason to access deception assets, every alert generated by DentiGrid is a **100% verified True Positive**.

---

## Key Features

- **ECS v8.11+ Normalization:** Automated Elasticsearch ingest pipeline maps all incoming JSON/Syslog telemetry directly into the Elastic Common Schema (ECS).
- **Zero-False-Positive SIEM Alerts:** High-confidence detections for internal lateral movement (`T1021.002`), credential abuse (`T1078`), port scanning (`T1046`), and ransomware payload staging (`T1570`).
- **Turnkey Kibana Dashboards:** Pre-built visualizations including real-time threat maps, MITRE ATT&CK matrices, targeted protocol breakdowns, compromised account tracking, and live incident triage feeds.
- **Elastic Security Detection Rules:** Out-of-the-box pre-packaged SIEM detection rules with sub-second MTTR containment capabilities.
- **Fleet & Elastic Agent Ready:** Fully compatible with Elastic Agent Fleet policies via `httpjson` (polling API Gateway) or `logfile` (Syslog/local files).

## ECS v8.11 Field Mappings

| DentiGrid Telemetry Field | ECS v8.11 Normalized Field | Description |
| :--- | :--- | :--- |
| `timestamp` / `time` | `@timestamp` | Event timestamp in UTC |
| `src_ip` / `sourceIP` / `ip` | `source.ip` | Attacking source IP address |
| `src_port` / `spt` | `source.port` | Source ephemeral port |
| `src_host` | `source.domain` | Source workstation / host FQDN |
| `src_user` / `user` | `user.name` & `user.domain` | Compromised user account probed |
| `dest_ip` / `dest` | `destination.ip` | Targeted DentiGrid decoy IP |
| `dest_port` / `port` | `destination.port` | Decoy port (e.g. 445, 3389, 22) |
| `dest_host` | `destination.domain` | Decoy hostname |
| `transport` / `protocol` | `network.transport` / `protocol`| Transport protocol (tcp, udp, smb, rdp, ssh) |
| `node_id` / `nodeId` | `observer.name` | Decoy node / sensor cluster ID |
| `signature` | `threat.indicator.name` / `description` | Threat signature name |
| `signature_id` | `threat.indicator.id` | DentiGrid signature ID |
| `mitre_tactic` | `threat.tactic.name` | MITRE ATT&CK Tactic |
| `mitre_tactic_id` | `threat.tactic.id` | MITRE ATT&CK Tactic ID (e.g. TA0008) |
| `mitre_technique` | `threat.technique.name` | MITRE ATT&CK Technique |
| `mitre_technique_id` | `threat.technique.id` | MITRE ATT&CK Technique ID (e.g. T1021.002) |
| `severity_id` | `event.severity` & `event.risk_score` | Normalized severity (1-10) and risk score (10-100) |
| `raw_payload` / `payload` | `dentigrid.deception.raw_payload` | Raw attacker command / payload string |
| `dropped_file_path` | `file.path` | Dropped ransomware/malware path |
| `sha256` | `file.hash.sha256` | SHA-256 hash of staged payload |
| `heuristic_classification` | `dentigrid.deception.heuristic_classification` | Edge-AI payload verdict |

## Configuration & Ingestion

### Option A: Elastic Agent Fleet Policy (Recommended)
1. In Kibana, navigate to **Management → Integrations**.
2. Search for **DentiGrid** and click **Add DentiGrid**.
3. Configure the **DentiGrid API Gateway** URL (`https://api-gateway.dentisystems.com/api/attacks/recent`) and your API Key.
4. Deploy the policy to your Fleet Agents.

### Option B: Direct Ingestion via Logstash / Filebeat / REST API
Configure your HTTP collector or Logstash to send directly to Elasticsearch with the pipeline parameter:
